# AccessMap — 9-апта: Frontend

8-аптада жоспарланған «Мүмкіндігі шектеулі адамдарға арналған қолжетімді нысандардың интерактивті картасы» жобасының интерфейсі.

## Беттер
- `index.html` — басты бет
- `map.html` — нысандар каталогы және интерактивті карта-макет
- `register.html` — тіркелу формасы
- `login.html` — кіру формасы

## Файлдар
- `style.css` — адаптивті дизайн
- `data.js` — тек демонстрациялық нысандар
- `app.js` — мәзір, іздеу, сүзу, таңдау, формаларды тексеру

`index.html` файлын браузерде ашыңыз немесе VS Code Live Server қолданыңыз.

**Назар аударыңыз:** барлық нысандар ойдан құрастырылған. Карта шынайы географиялық карта емес, нақты маршрутты немесе қолжетімділікті растамайды. Тіркелу және кіру деректерді сақтамайды. PHP/MySQL, нақты карта, пікірлер, таңдаулылар және маршруттар болашақ кезеңдерге арналған.
